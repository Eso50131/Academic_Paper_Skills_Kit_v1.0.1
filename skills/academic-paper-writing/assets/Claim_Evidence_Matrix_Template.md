## Instructions

- Create one row for each material claim, not every trivial sentence.
- Break compound sentences into separate claims when they require different evidence.
- Cite primary evidence where possible.
- A user's confirmation is not the same as independent verification of raw data.
- Mark a claim `LS` if evidence supports only a limited scope.
- Never mark `PV`, `NC`, or `US` as verified without new evidence.
- If a claim is contradicted, record the conflicting source and do not silently retain the claim.
